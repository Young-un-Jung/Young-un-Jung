## 🏆 Featured Project

### 🌿 CLIMB: 기후를 넘어 식물의 내재적 생리 상태 분석
**KISTI 2025 DATA·AI 경진대회 출품작 (Team DeCO)**

> **"단순 예측을 넘어, 모델의 판단 근거(XAI)와 작동 한계(LLM)까지 규명하다."**

특용작물(천궁)의 기능성 성분을 예측하기 위해 **해석 가능한 트랜스포머(Interpretable Transformer)**를 구축하고, LLM을 활용해 모델의 강건성을 검증한 프로젝트입니다.

| Domain | Technology | Key Achievement |
| :--- | :--- | :--- |
| **Model** | **Transformer (Encoder-Only)** | 시계열 데이터의 장기 의존성(Long-term Dependency) 학습 및 **OOD(SSP5)** 예측 성공 ($R^2$ 0.91) |
| **XAI** | **SHAP & Permutation Importance** | 환경 변수보다 **식물 생리 반응(광합성 효율)**이 성분 축적의 핵심임을 규명 |
| **Validation** | **LLM (Mistral-7B) & Quantization** | 가상 극한 기후 데이터(SSP6) 생성 및 스트레스 테스트를 통한 **모델 작동 한계(Operational Boundary)** 규명 |
