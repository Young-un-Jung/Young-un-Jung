## 연구

**수치형 표 데이터 토크나이징** · 2026.05 – 2026.09 (종료)  
LLaMA-3.2-1B에 수치 피처를 넣을 때 긴 문자열 대신 피처별 분위수 토큰 하나(CDF-SQ)를 쓰는 방법을 연구했습니다. 10개 데이터셋에서 입력 길이, 열 순서 민감도, 학습 비용과 정확도 사이의 trade-off를 비교했고, 새 임베딩의 초기화가 적응 속도를 바꾸는지 사전 등록한 반복 실험으로 확인했습니다.

**표 데이터에서의 신경망 상호정보량 추정** · 2026.09 – 진행 중  
정답 MI를 알 수 있는 벤치마크 구성(Lee & Rhee, NeurIPS 2024)을 표 데이터로 옮겨, 같은 학습량에서 추정기가 언제 정답을 벗어나는지 정리하고 있습니다.
